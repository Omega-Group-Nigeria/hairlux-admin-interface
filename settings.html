    NB — column guide
    • Window (min) — how many minutes define this rule (before the appointment for walk-in, or after booking for home service).
    • Refund % — how much of the payment is returned to the customer’s wallet when this rule applies.
    • Forfeiture % — how much is not refunded; refund % and forfeiture % must always add up to 100.
    • Customer — whether the customer is allowed to cancel the booking in this situation.
    • Admin — whether an admin can cancel the booking in this situation.
